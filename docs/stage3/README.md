# 第三步：独立听力与混课词汇审阅版

本步承接已批准的第二步提交 `2c6d3b38866dcfbcf101974302609c470f1d2443`。交付目标是完整的听力模块、跨课词汇复习及其运行证据。正式首页接入、与旧站的整体回归及生产发布属于第四步。

## 打开与审阅

- 学生页面：`dist/stage3/HSK1-Step3-Listening-Vocabulary.html`。这是含音频、题库、样式和程序的单文件；下载后用普通浏览器打开。应用内的文件预览器可能限制脚本或声音，遇到这种情况请下载并用 Chrome、Edge 或其他支持 HTML 音频的浏览器打开。
- 教师手册：`dist/stage3/HSK1-Step3-Teacher-Guide.html`。逐课列出全部题目、正确选项文本、原文、拼音、越译、错因、词卡和教材出处。
- 可维护源码：`new-hsk1/hsk1/stage3/`。模块页面从本目录载入资源；音频按课延迟加载。
- 构建摘要：`dist/stage3/build-manifest.json`。给出单文件哈希、体积和教材覆盖数量。
- 音源清单：`new-hsk1/hsk1/stage3/media-manifest.json`。每个音段都有源轨、起止、原上传轨与站点轨哈希、裁片哈希和字节数。

学生端选项会在每个新练习轮随机排列，因此教师审阅时应以“中文原文＋正确的越语选项文本”为准，不能固定要求学生选手册中的 A、B、C 或 D。

## 本步内容

| 内容 | 数量与口径 |
|---|---|
| 听力 | 15课，每课5题，共75题；每课2个词语、2个完整话轮、1段短对话 |
| 听力题面 | 中文原录音，学生选择4个越语选项中的对应意义 |
| 提交后反馈 | 本题结果、正确选项、所选项解释、其余选项错因、原文、拼音、越译、关键词、教材页码 |
| 词形 | 全册319个不同中文词形，含教材专名与扩展词 |
| 词卡 | 344条按课义区分的卡片；完整覆盖342个索引课次归属，并补保同课“天”和“上”的不同义项 |
| 词卡音源 | 330条有本课独立词音；第4课数字表14词保留卡片并明示暂无独立原音 |
| 媒体 | 75听力＋330词卡，共405个媒体ID；相同音段可共享编码内容 |

“词形”“义项卡”“课次归属”“媒体ID”是不同统计口径，不能用其中一个数字替代其他口径，也不能把听力75题或词卡自评加进第二步作业的225项分母。

## 学生如何练听力

1. 在“Luyện nghe”勾选已经学过的一课或不连续的多课；选择全部题或最近答错的题。选择变化只影响下一轮，正在做的一轮保留自己的题目和选项顺序。
2. 点击“Bắt đầu lượt nghe”，再主动点击播放。首次呈现只含越语题干和选项；中文、拼音和关键词在提交前不会放进当前题面的可见文本或辅助标签。
3. 可暂停、继续、从头重听，并选择0.65、0.75、1、1.25、1.5倍速。默认1倍；重听不扣分。
4. 选答案后点击“Nộp câu trả lời”。每题提交后显示解析；提交后才可进入下一题。回看已做题不会重新评分。
5. 看本轮“已提交／总数”“答对／已提交”和完成后的整轮结果。全册首次成绩与最近成绩分开显示，重练不会覆盖首次成绩。

课堂使用可安排“先听懂意义—重听确认—提交看反馈—再听并复述”。已熟悉的学生可直接用正常速度；需要帮助的学生自行减速、重听，再回正常速度。页面没有强制只播放一次或按听取次数扣分。

## 学生如何混课复习词汇

进入“Ôn từ vựng”，勾选1—15课中任意组合。页面显示选中课数、义项卡数、不同词形数和过滤后的卡数。支持全部、未熟悉、需再练、到期／新词四组，可按课序或打乱。

- 中文→越语：先回忆词义。多义词在中文正面给出已学的短语语境，明确本卡目标意义；拼音和越译在翻面后出现。
- 越语→中文：先说或写出中文。中文、拼音、语境和词音都在翻面之后显示，避免音频先给出目标答案。
- 翻面以后，学生选择“Chưa nhớ”（未记住）、“Còn khó”（困难）、“Đã nhớ”（记住）。这是学习者自评，页面没有把自评当作机器判定的翻译对错。
- 同形异义保留不同卡片，例如“想”的思念义与意愿义、“在”的不同用法、“天”的天气／天数、“上”的方位／上车／上学。来源详情保留所选课的原始页码。
- 相同义项支持合并并保留各来源。当前教材整理后的344条记录各有独立义项ID，不能声称实际存在一个并未出现的跨课同义合并示例；引擎的同义合并行为另用明确软件样本验证。

## 复习日程

| 本次自评 | 下次复习 |
|---|---|
| 未记住 | 回到起始级，10分钟后 |
| 困难 | 保持级别，1天后 |
| 记住，且是新卡或已到期 | 按1、3、7、14、30天逐级安排，最高保持30天 |
| 未到期又选择记住 | 保持原级别和原到期日，避免反复点击把复习推得越来越远 |

当前轮的卡片列表、位置、是否翻面、自评结果分别保存。每卡每轮只允许一次自评；返回或刷新不会重复累计。日期按照学生浏览器当地时间显示。这是公开、可解释的固定练习日程，没有声称使用经过训练的个性化记忆模型。

## 保存和恢复

听力与词卡使用独立的第三步存储键 `ran_hsk1_stage3_v1`。页面在学习动作后保存到当前浏览器，打开页面本身不会先写一份空记录。没有自动跨设备同步。

“Lưu bản sao / mở lại tiến độ”可下载JSON，也可选文件或粘贴JSON，先检查再确认打开。恢复会校验版本、题目与义项、课次、冻结队列、选项顺序、答案、内容指纹和日程；分数由答案重算。无效输入不会替换当前进度。打开检查过的备份前保留恢复点。

当浏览器拒绝保存、容量不足或其他标签页更新记录时，页面会说明情况，并保留当前页内存中的进度供下载。多标签保护用于减少无意覆盖；普通浏览器存储不是具有事务隔离的多人数据库。JSON是用户可编辑的学习备份，不是防作弊凭据。

恢复只回到该题／该卡及其答案；声音保持停止，由学生主动重播整段。不会在重新打开页面时从一个音节中间自动播放。

## 原音处理与检查口径

本模块使用用户提供的教材录音。对原RAR解出的93轨与站点93轨做了音频包及解码PCM核对：音频包一致；原文件解码多出的529个前置采样点（44.1kHz，约0.012秒）对齐后，PCM逐字节一致。封面／标签变化与此不矛盾。详细证据在 `audio-source-manifest.json` 与 `audio-audit.md`。

题目使用独立裁片，播放在媒体自身的结束事件停止。裁切先解码再按原轨时间截取，避免复制MP3包造成切口漂移；之后编码为单声道24kHz、48kbps MP3以控制下载量。这是重新编码后的教材原声，不是无损裁切，也没有使用合成语音冒充录音。

检查必须分开说明：教材页的文字核对、原录音与站点来源对齐、自动识别全文和词戳、波形／裁片边界检查、解码、实际浏览器播放。当前工具不能直接让本助手用听觉听取录音，因此报告不能写成人工逐条耳听认证。自动识别尤其可能错认同音词、孤立音节、人名和重复读音；不能用一个模型的字面识别结果擅自改教材答案。

## 复现第三步

在具有Node.js、Python、ffmpeg和ffprobe的环境中，按顺序运行：

```bash
python tools/build-stage3-media.py
node tools/build-stage3.cjs
node tools/build-stage3-teacher.cjs
node --test tools/tests/stage3-engine.test.cjs
node tools/serve-stage3.cjs
```

最后一条启动仅允许第三步公开资源的本地预览服务，默认端口18767。`tools/tests/stage3-browser.cjs`用于隔离CI浏览器回归，不运行在教师或学生现有的登录浏览器中。两个音频证据工作流和一个浏览器验证工作流仅在第三步审阅分支执行，不含部署动作。

最终验收状态、对应提交、工作流运行、实际截图和尚未覆盖的环境，以本步的 `acceptance.md` 及 `tools/tests/results/stage3-browser.json` 为准。
