# 第三步数据与产品约定

本步基于已批准第二步提交 `2c6d3b38866dcfbcf101974302609c470f1d2443`。只写第三步目录、构建/测试/证据文件，不改前两步、生产课程、访问控制或旧存档。第三步为独立听力和混课词汇审阅版；第四步承担正式整合。

## 听力题库

三个JSON文件：`new-hsk1/hsk1/stage3/data/listening-01-05.json`、`listening-06-10.json`、`listening-11-15.json`，各为25个题目对象的数组。每课5题，合计75题。优先每课2个词语/短语、2个完整句子、1个短对话；前几课可依实际材料灵活安排，保持任务自然。

每题字段：

```json
{
  "id": "l01-listen-01",
  "lesson": 1,
  "kind": "word",
  "promptVi": "Nghe và chọn nghĩa đúng.",
  "audio": {"track": "1-6", "start": 0, "end": 2.772, "timingBasis": "site-candidate"},
  "transcript": [{"zh": "谢谢。", "py": "Xièxie.", "vi": "Cảm ơn."}],
  "options": ["Cảm ơn.", "Xin lỗi.", "Tạm biệt.", "Xin chào."],
  "answer": 0,
  "explanationVi": "...",
  "optionFeedback": ["...", "...", "...", "..."],
  "keywords": [{"zh": "谢谢", "py": "xièxie", "vi": "cảm ơn"}],
  "skill": "...",
  "source": {"printPages": [3], "pdfPages": [18], "section": "生词"}
}
```

示例仅说明字段，不是已核实的最终题目。`audio`起止先用站点候选时间码，最后必须经音源/边界核对并生成独立片段；听力媒体ID使用题目ID。`transcript`逐轮写原音中文、拼音和对应越译，角色只有确有依据时另加`speaker`。所有选项用越语且语义互斥，不靠“他/她/它”同音字、未播出的身份或无依据性别判分。题干不能提前泄露目标中文、拼音或答案。

每题作答后主动提交才显示原文、拼音、越译、关键词及错因；允许无限重听，不扣分。支持任意单课、多课混合、已错题重听。题目和选项顺序在当前轮冻结；恢复回到原题并保留答案，由学生主动重播，不自动从半个音节播放。首次与最近成绩分开，每题首次只能写一次；听力分母与第二步225项保持独立。

## 词汇数据

三个JSON文件`vocabulary-01-05.json`、`vocabulary-06-10.json`、`vocabulary-11-15.json`，每个为该范围课程的词汇义项记录数组。以第一步course-map的全部342个索引课次归属为基础，保留第12课“天”和第14课“上”在同课的不同义项，预计344条记录；最终以教材核对结果为准，不用数量掩盖漏词。

每条字段：`id`（如`v-l01-lex-bbc044d7ea-s1`）、`lexId`（第一步entry_id）、`senseId`（稳定的词义ID）、`lesson`、`zh`、`py`、`vi`、`senseZh`、`cueZh`（可选，已学语境短语，尤其多义词）、`category`（ordinary/proper_noun）、`extension`（布尔）、`source`（printPages/pdfPages/section）、`audio`（候选track/start/end/timingBasis，数字表无独立原音可为null）。不得把其他课的一整词录音冒充本课词的单独录音。

通常`senseId=lexId+'-s1'`；同形不同义按course-map.repeated_or_polysemous_terms的senses顺序编号s1/s2/s3。例如第3课想s1、第6课想s2；在第7/8/11课s1/s2/s3；天第12课两义s1/s2；上第9课s1，第14课两义s2/s3。跨课真正同一义项才合并，合并必须保留全部课次来源。数字14词正常收录，不能因缺少独立录音而漏词。词条越语以本课义为主，标注8个教材扩展词与教材专名分类。

任意勾选1—15课，实时显示选中课数、合并卡数、不同词形数及来源。支持全部、未熟悉、需再练、到期过滤和打乱，中文→越语及越语→中文回忆；翻面之后才能自评。自评与听力客观错题分开保存。稳定义项ID承载熟悉度，不因换译文措辞就粗暴重置。

间隔安排采用明确、可解释的练习日程，不宣称已个性化训练的模型：未记住→10分钟后，困难→1天后，记住→1/3/7/14/30天逐级安排；未到期反复点记住不连续升阶。卡片的自评、查看答案和当前队列分别保存，防止刷新或返回刷高熟悉度。到期按浏览器当地时间显示。

## 播放与保存

默认1倍；允许0.65、0.75、1、1.25、1.5；优先使用浏览器保调属性。仅由学生主动播放；全站本模块同一时间只有一个音源。暂停、从头重播、切题停止、切模块停止、加载失败及重试均明确。最终独立片段使用媒体自身ended事件，避免按固定墙钟定时器截句。

第三步使用独立APP/存储键，不自动迁移第二步或旧版。JSON显式导入必须验证题目/义项ID、类型、成绩和日程；成绩由答案重算；先预览后替换、保留恢复路径。输入损坏、容量不足、多标签更新不能静默覆盖作业。

## 文件分工与实际验收

题目作者分别负责1—5、6—10、11—15的两份JSON与对应`docs/stage3/content-XX-YY.md`，不改公共程序。引擎作者负责`engine.js`和Node测试，并提供API约定。根代理负责页面、播放器、构建、CI和最终打包。来源审阅者核原RAR/站点音频、原文页码与裁切边界；独立审阅者只改独立审查文档。

音频内容核对区分实际听取、自动识别、教材文字核对、媒体解码和浏览器播放；未做的检查不得写成已做。当前模型工具不能直接接收音频；计划使用可追溯的自动语音识别辅助与教材逐段对应，并明确其边界。

验收至少覆盖75道听力完整操作、全部五档速率、重播/暂停/切题/加载失败、跨课混合与错题、答案提交前隐藏、总分与首次/最近、词汇全选/不连续选课/清空/多义词/数字缺音频、翻面自评/到期与提前复习、刷新/备份/多标签，以及最终导出物。
