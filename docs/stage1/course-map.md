# 第一步：教材课程事实映射

**范围：15课课程映射、教材与基线源码差异、第3课样板的已教范围。** 这份文件与 `course-map.json` 同源；不包含全书新作业或新听力题。

## 1. 核心结论与计数口径

上传教材共144个PDF物理页。课程为15课、45篇课文、40个正式语法点。正文从印刷1页对应PDF16页开始，直到词表印刷128页均为“PDF物理页 = 印刷页 + 15”。课名与全部40个语法标题和基线课程对象相符。[教材 PDF7、12–14；印刷1–128 / PDF16–143]

书末索引人工转录结果为 **319个不同词形：307个普通词形（含8个星号扩展词）及12个专名**；按索引列出的课号展开为 **342个课次归属**。45个生词音轨对应330行，另有第4课数字表14个索引词；其中“天”在第12课、“上”在第14课各有同课不同义的重复行，因此不能把330 + 14当成344个不同词。教材使用说明的“300词并略有扩展”与这些索引单位不同。[教材印刷20–21、88、91、105、109、122–128 / PDF35–36、103、106、120、124、137–143]

基线网站为336个课次词条、313个不同词形。已确认缺7个教材课次词条，并将“西安”提前放到第6课；8个教材扩展词被统一标为core。另有第3课第2篇漏句、部分人物/场景和越译义与教材不一致。下文保留证据及影响，第一步本映射不直接改动原课程。

| 计数对象 | 数量 | 使用方式 |
|---|---:|---|
| 不同索引词形 | 319 | 总词形清单；跨课复现去重 |
| 课次归属 | 342 | 选择几课合并复习的来源关系 |

- **textbook**：新HSK教程1(HSK3.0) (郭风岚、汤旭编著) (z-library.sk, 1lib.sk, z-lib.sk) (1)(3).pdf；66,692,625字节；SHA-256 `25d1aad102e4179307b5bc4f932927bbd244b3f4dd53edeb6cfd4dbbb8d4f2ba`。
- **objective_answers**：《新HSK教程1》客观题答案(5).pdf；1,040,826字节；SHA-256 `9e783c9deb889231a778d6776b65dbc04fc734eeca0fdfda1c9d99eb793104e5`。
- **audio_archive**：新HSK教程1+配套音频(3).rar；32,297,512字节；SHA-256 `19bde58bb2e35a430a28110e365546b8416e33a2e1b070d61543aada3db686cc`。

源码比较基线：`gh-pages`，提交 `069f9d956c9a600a91e6b4ce82241ceccc184dce`。比较实际加载后的 `new-data.js`、`new-enrichment.js`、`textbook-data-corrections.js`；音轨词序辅助来自 `_audio-work/all-vocab-1-15-compact.json`，并回看上传PDF的45个生词块。JSON中的 `baseline_site` 仅记录现有拼音/越南语释义，**不代表教材官方越译，也不表示已经逐条语言审校**。

- 使用本地上传教材PDF页图核对15课课名、起止页、45个课文/生词块和40个小语讲堂语法标题与页码。
- 人工转录书末词语表与专名表全部319个不同词形、课次与星号；与45个生词块和数字语法表对照。
- 对前3课语法及代表性后续义项细读，记录已教范围、多义再收录、同课重复行和新增题风险。
- 提取并阅读13页客观答案文字，逐课定位题组；核对部分答案页图及教材题型。热身图片答案只做覆盖定位。
- 安全枚举RAR，93个MP3逐一读取媒体元数据并解码检查；文件名与教材标注及仓库音轨清单对应。
- 与基线new-data.js、new-enrichment.js及textbook-data-corrections.js的有效课程对象交叉比较；音轨词序表只作辅助，并回看教材生词块。

以下每课“普通”不含星号词，“扩展”专列星号普通词，“专名”按教材自己的专名分类。教材将“中文、汉语、汉字、王老师”等放在专名表，本映射照录分类，不另行改写其语言学归类。全部词条的精确索引页、课文词页、基线释义和是否漏项均在JSON中。
