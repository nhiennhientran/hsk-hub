## 已修复的问题

| 问题 | 修复 |
|---|---|
| 原规则要求全部改对才解锁 | 新引擎以5题完整提交为完成条件 |
| 原翻译为选择题并混入自动分母 | 新自由输入题采用新ID；翻译无自动成绩；分母10 |
| 排序存在另一自然语序 | 第3题明确要求以“她”开头，解释不泛称其他自然句法为错误 |
| 继承样式隐藏已提交句子中的禁用词块 | 仅在样板已组句区域覆盖可见性 |
| 重做翻译后找不到上次截图稿 | 保留“查看最近已保存译文”入口，读取提交快照 |
| 题卡更新后键盘焦点丢失 | 恢复已选按钮或下一可用词块/撤销按钮 |
| 漏答补全后上下计数不一致 | 同步顶部提示，补全后清除警示 |
| 保存失败恢复后旧警告仍显示 | 成功恢复写入时清除对应失败警告 |
| 历史截断后误显示绝对提交次数 | 改为“最近提交稿”和“最近提交记录” |
| 越语“自批”含义不明确 | 统一为“自动评分”Chấm tự động |

## 测试环境边界

页面测试在专用软件测试浏览器运行，不读取真实学生记录、不登录正式站点，也不连接教师消息系统。真实学生的系统中文输入法、Safari、实际iPhone/Android设备和跨设备云同步不在本步已验证声明内。Unicode中文输入、换行和文本保存测试不能写成已经测试所有输入法。

本会话浏览器不能访问本地文件协议，且本地HTTP开发地址被其客户端阻止。因此改用GitHub独立审阅分支的隔离CI运行真实Chromium页面测试；不以源码审阅或Node测试冒充页面实测。CI结果、截图和最终提交标识须以下文实际取回的证据为准。
