# HSK1 第一阶段：第3课样板与教材对应表

这是依据已确认四步计划完成的**第一步独立审阅版本**。范围是核实教材、固定数据口径、改正核心作业逻辑，并完成第3课15题样板。其他14课新题、跨课生词混合、独立听力模块和正式站点整合留在后续步骤。

## 打开样板

下载 `dist/stage1/HSK1-Step1-Lesson3.html`，在 Chrome、Edge 或 Safari 中打开即可开始。它是包含样板样式、题库和脚本的独立HTML；不需要安装依赖，也不连接教师收件服务。部分手机文件预览器不执行JavaScript，需用浏览器打开文件。

开发者可以从仓库根目录执行：

```sh
node tools/serve-stage1.cjs
```

之后访问 `http://127.0.0.1:8765/`。该开发服务采用文件白名单，只提供本步样板需要的页面、样式和脚本，不提供目录浏览、教材上传文件或原站点门禁。

重新生成单文件：

```sh
node tools/build-stage1.cjs
```

独立样板没有登录步骤，不加载生产站点的认证或会话脚本。正式整合时应复用正式站点的访问控制；不能把本步样板页面直接作为已完成门禁整合的生产入口。

## 本步可以实际验收的功能

| 功能 | 样板行为 |
|---|---|
| 选择题 | 5题，每题4个选项；显示A–D，选项顺序在本次作答中保持稳定；整组提交后显示成绩和越语解析 |
| 组句 | 5题；点击打乱词块组成完整句子；可撤销、移除和重排，支持键盘按钮操作；提交后给出答案与说明 |
| 越译中 | 5题，输入学生自己的中文；只检查是否填写，不判断语言对错，不显示参考答案 |
| 计分 | 全课15项作业；自动评分分母10，人工翻译5题单列；未提交的客观题不伪装成已评分 |
| 解锁 | 同课先选择、再组句、再翻译；完整作答并提交即可解锁，不设置正确率门槛 |
| 重做 | 首次成绩保留；最近成绩另存；重做前面一组不重新锁住后面已完成的组 |
| 截图稿 | 5道越语题目与已保存的中文原文、姓名/班级、保存时间同页呈现；可用浏览器打印或存PDF |
| 恢复 | 自动保存新版本草稿；可导出JSON备份、检查后恢复；替换前保留上一份恢复版本 |
| 旧数据 | 仅通过显式导入迁移；原v2记录完整归档，旧翻译选择题不会冒充新自由翻译已完成 |

界面用越南语解释操作，中文文本保留汉字。选择和组句在提交整组之后才显示解释；自由翻译页面没有机器评分字段。老师参考与可接受变体在 `teacher-reference.md`，不由学生页面加载。仓库仍是公开源码，文档分离不等于教师权限系统。

## 建议的验收动作

1. 直接尝试进入第2、3组，确认未开放；尝试漏答提交，确认不能解锁。
2. 在选择题故意答错一题并完成5题，检查显示4/5，同时组句开放。
3. 完成组句，检查总计已自动评分10题，译文仍不进入分数。
4. 输入5句中文，包含换行和标点，保存后打开截图稿；确认原文完整且没有对错标记或参考译文。
5. 重做前一组，确认首次分数保留；重做翻译只写新草稿，仍能打开上一份已保存截图。
6. 刷新或导出再恢复备份，确认题目、选项/词块顺序和答案保持一致。

## 文件索引

- `course-map.md` / `course-map.json`：15课教材页码、生词、语法、客观题答案覆盖与93条音频对应关系，以及已识别差异。
- `sample-evidence.md`：第3课每道题的教材来源、范围和命题边界。
- `teacher-reference.md`：教师人工反馈使用的译文参考；学生页面不加载。
- `state-contract.md`：提交、首次/最近成绩、解锁、备份与v2迁移规则。
- `baseline.json`：固定的生产基线、来源分支与原文件校验值。
- `independent-review.md` / `acceptance-review.md`：独立源码与产品审查。
- `test-report.md`：本次实际执行的测试结果、证据路径和尚未覆盖的环境。

## 边界

样板中“已保存”只表示已保存作业，不表示老师已经收到或批改。截图需要学生自己发送。自动评分统计描述这10道练习的结果，不把它当成整课掌握程度的完整测量。练习全部使用教材第1—3课已学内容；排序题有可能存在自然的其他语序，必要时通过明确题干或登记可接受答案处理。

这是保留原站风格的独立第3课样板。现有15课正式页面、音频文件、正式门禁和旧进度键不在本步修改范围内。确认本步验收后，再按照已同意的四步计划进入第二步。
