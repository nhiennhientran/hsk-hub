## 2. 教学范围

样板使用第1—3课已学内容。第3课的正式教学点为“是”字句、“的”和“吗”问句，同时复用课文里的国籍、人物关系、忙碌程度和想念表达。

| 项目 | 本样板采用的范围 |
|---|---|
| 人称 | 我、你、她、我们、你们；不要求用尚未列入第3课正式词表的“他” |
| 身份与关系 | 老师、学生、同学、姐姐、女朋友、中文老师 |
| 国籍 | 中国人、法国人、泰国人 |
| 是 | 身份／国籍介绍，及“不是”的否定形式 |
| 的 | 所属、亲属与人物关系；按照教材说明，接受自由翻译中自然省略“的”的写法 |
| 吗 | 句末是非问句；与“哪国人”的提问功能区分 |
| 想 | 仅采用第3课“想念”的意义，不考“想要＋动词” |
| 还、工作 | 遵循课文“你工作还忙吗”的语境，不扩展其他用法 |

`new-data.js`是辅助交叉核对资料，不替代教材。例如该文件为“想”列出多个通用释义，本样板仍限定于教材第3课的“想念”义；课文引用以PDF原文为准。

## 4. 数据与记录兼容

样板是一个只含第3课的数组。浏览器使用 `window.HSKStep1Bank`，CommonJS使用 `require('./sample-bank.js')`。每题均显式标记 `kind`。

- 选择题和排序题共10道标记为 `assessment: 'automatic'`、`legacyCompatible: true`。它们的原ID与计分核心字段保持一致：选择题的 `stem/options/answer`，排序题的 `tokens/answers` 均未改变。
- 越南语题干、解析与逐选项反馈可以优化；这些修改没有更换原题的正确选项、词块或接受答案。排序第3题新增“以她开头”以界定练习要求。
- 五道自由翻译使用新的 `l03-translation-free-*` ID，标记为 `assessment: 'manual'`、`legacyCompatible: false`。旧版翻译选择题完成记录不能据此视为自由翻译已经完成。
- 学生题库的自由翻译对象不含 `answer`、`answers`、`options`、参考译文、正确性规则或语言质量评价。教师参考单独放在 `teacher-reference.md`，不由学生页面加载。
- 各题 `source.label` 是可供页面使用的简短教页提示。印刷页与PDF页并存，便于教师复核，不把内部审查内容显示给学生。

每课样板共15题：选择5题、排序5题、自由翻译5题。自动评分分母为10题；翻译只计提交完成度，不进入对错统计。独立听力及其他课的全面重编属于后续步骤，本样板不提前扩展。

## 5. 内容检查结果与边界

完成了第3课全部8页和对应答案页的视觉核对，并独立复核15题的越南语意义、中文表达与课程范围。四选一均有4个不重复选项和唯一合适答案；排序词块与登记答案一致。第3题排序已按独立审查意见增加开头限制。
