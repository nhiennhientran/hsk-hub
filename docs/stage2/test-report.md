## 执行边界

浏览器自动化只在隔离的GitHub Actions运行，访问本次代码的文件白名单开发服务，不连接生产页面、用户浏览器或登录会话。合成作答只用于检查保存与计分行为，不是学生的真实成绩。教师参考和学生网页分开，页面不加载翻译参考。

窄屏视口不是实机手机认证；操作系统中文输入法、Safari、真实课堂试用和后续独立听力属于尚未覆盖的环境或后续阶段。192 MiB只是保留极端合法历史时的导入大小上限，不代表手机能够实用地处理这一体积。
