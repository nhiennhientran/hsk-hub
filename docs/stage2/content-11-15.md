# 第11—15课作业内容依据（第二步）

本分卷为75道新编作业：每课5道ABCD选择、5道句子排序、5道越译汉自由作答。每课作业总数15、自动评分分母10、自由翻译5。所有新题均为`legacyCompatible:false`，不将旧题作答直接视为新题已完成。自由翻译的学生JSON只含题干、学习目标和出处等元数据；参考表达仅在独立教师稿中。

## 依据、核对范围与产品边界

这些题是根据教材学习范围编写的新练习，页码标示教学依据，不表示新题逐字来自教材或拥有出版社官方答案。本分卷没有把教材客观题答案PDF当作新题答案；题型采用短情境理解、语义选项、语序重组与受控迁移。

完成与得分分开：自由翻译只要求五题有实际作答并提交，教师无需在网页判分才能继续。其提交记录、截图证据、保存恢复、首次及最近一次成绩由公共第二步引擎实现；本分卷不新增评分流程或听力。独立听力与混课词卡属于第三步范围，本次未扩写。
