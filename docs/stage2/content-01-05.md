# 第1—5课作业内容依据（第二步）

本分卷共75题，其中第1、2、4、5课为60道新编题，第3课15道为第一步已确认样板的原样复制。每课选择5题、排序5题、自由翻译5题；自动评分分母为10，翻译只保存原文与提交状态。学生题库不载入教师参考答案。

## 材料核对与边界

主要依据为用户上传的《新HSK教程1》（郭风岚、汤旭编著）及第一步课程映射 `../stage1/course-map.json`。本次视读第1课印刷1—4页（PDF16—19）、第2课5—9页（PDF20—24）、第4课18—26页（PDF33—41）、第5课27—34页（PDF42—49）；第3课10—17页（PDF25—32）沿用已确认的逐页审定结果。PDF物理页＝教材印刷页＋15。

《新HSK教程1》客观题答案用于核对教材题型与既有练习答案，不是新编题的官方答案。第1—2课没有相应客观题答案栏目，不能虚构官方评分依据。

| 课次 | 本课训练重点 | 具体边界 |
|---|---|---|
| 1 | 问候、感谢、告别、敬称与复数称呼 | 不引入是、我叫、吗等后课句型；真实短句允许只有2—3个词块。部分高频礼貌用语在不同任务里复现，是词汇极少时必要的练习，不以硬拼长句追求表面不重复。 |
| 2 | 问名、自我介绍、道歉回应、基本主谓宾语序 | 认识与很高兴按本课语块训练；不用第3课的、吗。人名在题干给出或已见教材。 |
| 3 | 是、的、吗及关系、国籍、想念 | 第一阶段样板原样保留；想仅为想念。 |
| 4 | 家庭、数量、年龄、有/没有、呢 | 二/两要有明确数值情境；口/个按对象解释；不漏掉数词表中的八或词表中的爸爸。 |
| 5 | 日期、星期、名词谓语、会表示技能、新电脑与喜好 | 会不使用将来义；菜依课文为菜肴；合理含是日期译法、星期日/天和面条儿/面条均由教师按题意接受。 |

## 数据验收口径

新编60题均使用 `lXX-s2-*` 新ID及 `legacyCompatible: false`，不沿用旧站成绩。第3课直接读取第一步 `sample-bank.js` 中的对象，保持完整字段和兼容标志不变。选择题均有4个不重复选项、唯一答案索引及4条对应越南语反馈。排序答案必须由全部给定词块组成；本分卷明确登记时间成分和并列主语的合理变体，或在题干中限定开头。自由翻译对象没有答案、备选项、解析或正误评分规则。

内容记录与浏览器运行验收分开。程序需继续验证排序多解、首次成绩、提交与解锁、草稿恢复、中文输入和截图稿；本记录不把尚未完成的界面检查提前写为通过。
