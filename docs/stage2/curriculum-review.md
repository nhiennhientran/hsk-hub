# 第二步：教材范围与来源独立审校

本审校覆盖新增14课210题，以及保持第一步样板不变的第3课15题，共225题。审校对象是第二步隔离题库，正式课文、原有音频和混词模块不在本次修改范围。

当前状态：第1–15课225题已完成助手独立逐题阅读，覆盖题干、排序题可见越语意义、答案、解析、选项反馈、出处和75道自由翻译教师参考。已定位的问题修订后完成复核，未发现未解决的教材累计范围阻断。下方版本记录绑定已审阅的225个题目ID及3个题库、3个教师参考的SHA-256。

## 核查依据及机器检查边界

第一手依据为用户上传《新HSK教程1（HSK3.0）》（郭风岚、汤旭编著）及《新HSK教程1》客观题答案。第一步已核的完整课程事实见 [course-map.md](../stage1/course-map.md) 与 [course-map.json](../stage1/course-map.json)。教材正文的PDF物理页等于印刷页加15。教材索引有319个不同词形、342个课次归属；两个数均不能直接当作本次作业题数。

助手逐题检查以下内容：正确答案和题意实际使用的词义是否已教；句式是否有截至当课的教材依据；选择题的干扰项是否仍可理解；排序是否存在自然的合理词序；越译汉教师参考是否承认自然变体；教材页码是否支持该题；新编题是否被误称为官方题或官方答案。

`tools/tests/stage2-curriculum.cjs` 只检查可明确计算的来源约束、印刷/PDF页对应、引用是否超出当前课、第一步样板是否保持一致，并汇总需要逐题语义判断的词义提示。它不把汉字或词面分割当成句法验证，不以字符串匹配判定越译汉正确，也不以“所有字符都在词表里”证明一句话没有超纲。

教材中的词语表、课文语块、先行例句和教师补充词是不同来源层次。某词正式索引归后课，但早期教材已有明确例句，不宜机械判成绝对不可用；作者必须指出提前采用的具体页码，并控制它不是题目的隐藏难点。人物名只作为明示的人名使用，不按汉字逐个判超纲。数词组合、姓名称谓、国名加“人”等透明组合也需要结合已教规则判断。

本次“逐题阅读”指全部225道项目作业及其配套说明；教材范围核对复用第一步对原PDF建立的逐课词条、语法和课文映射，并对具体歧义返回原页查证。例如本步复看印刷25、56页核他／们组合与外边的提前出现，印刷82、88、106、117页核进行否定、句末了、离合词及要的时长义。此结论不声称把教材144个PDF页逐字重读，也不声称本步逐条试听全部配套音频。

## 各课范围与高风险点

第1–5课的具体判断：第1课2–3词块的真实问候句适合起步阶段；第2课“我是学生”有教材印刷8页依据，“不/是”已在7页列词，不把它机械视为第3课才可出现；第4课的八、爸爸确有印刷20、22页依据，不能因旧站漏项排除；第4–5课的时间前置、并列主语交换及自由翻译中的的/量词/数字/儿化变体有记录。第3课15题已重新核对并与第一步样板比对。

已报作者并复核完成的修订：`l01-s2-choice-05`解析把“谢谢表达 sự cảm ơn”改成完整越南语说明；`l02-s2-sort-04`解析把非目标“用”改为越语。另复核道歉者措辞与第三人称问法提示的优化；该类修订不改变正确答案。

第6–10课的具体判断：第6课西安饭店按餐馆专名使用，想/坐/号按本课新义；第6课第5道选择中的他们由第1课印刷2页的们和第4课25页的他透明组合，来源已补全，不因为整词索引在第14课而机械拒绝。第8课外边虽在词汇索引另列第9课，但印刷56页/PDF71页方位语法栏已经列出；教师说明已明确优先房间外，不声称外边从未出现。第9课家作为书店量词、和作为伴随及第的序数功能，第10课斤的扩展单位身份和不太贵的程度义均有明确语境。

第6课自由翻译1、4和第8课自由翻译3，原先可照抄排序整句，现分别迁移为老师的手机号、姐姐坐出租车及超市前见；页码和教师参考同步修正并已复核。教师参考中“很 ngon”改为“rất ngon”，一斤=500克说明的位置改为本课范围说明/前面的选择题。自由翻译里列出的手机号码、前面等自然变体仅供教师接受学生自发表达，不作为学生必须掌握的新词或自动评分词面。

第11–15课的具体判断：第11课没／没有对进行的否定有印刷82页依据，读大学呢可表示持续情况，不机械要求正在。第12课了限定新情况，未把过去时间与了逐词对应；热水、来／到公司均可由已教词义和句法支持。第13课能／可以在自由许可问法中均可接受，双宾语角色明确，不把任意动词泛化为双宾动词。第14课睡了一觉、下了班有印刷106页直接例证；都没与没都不混同，女性复数由可见越语题干提供。第15课爱、独立西安、机场／接、要的所需时长义均按本课范围使用，住与在某地的意思区别在教师参考保留。

选择题和排序按明示题意审查唯一性或自然变体；自由翻译允许本课及此前句型的自然变化，也允许教师接受学生自发的正确扩展表达。这个人工评阅边界不是自动词面评分。两位助手分别承担教材范围与语义公平性审校，并交叉同步纠错；它不构成真人专家或母语教师认证。

末批复核的具体修订：第13课排序2补收“我问你一个问题，可以吗？”这一题干允许的自然许可问式；第15课选择1考还、排序1考也，选择题中不同时设置两个同义正确选项；第15课自由翻译3由两小时改为三小时，避免直接复用选择题的整句，并同步教师参考和目标。第14课选择2的目标改为“没否定动作的发生”。第13课排序4的越语意义原已明确“妈妈给弟弟两个鸡蛋”，因此把两个转而修饰弟弟会改变题意，不能当成同义排序答案。

当前75道排序共登记95个可接受整句字符串；该数不是题数，也不意味着穷举所有语用情境。75道选择各按题设审查答案，75道自由翻译仅供教师评阅。本记录按最终文件SHA和全部题目ID绑定，文件发生变化时检查会要求复核，不能把这次结论无条件延伸到后续版本。
