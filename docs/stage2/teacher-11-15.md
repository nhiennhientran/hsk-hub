# 第11—15课教师参考与反馈提示（第二步）

本稿只供教师审阅，学生题库及页面不加载。共25道自由翻译，网页不判对错、不评分、不以机器判断限制下一组解锁。参考句是合适的表达样例，不是唯一标准答案。教师先看学生是否完整传递题意，再反馈词义、语序与字形；自然省略、代词关系、时间位置和等义表达按具体语境处理。不要把越语đã／đang／sẽ机械逐词等同了／正在／会。

每课另列5道选择和5道排序，供人工核查机器答案。选择字母只对应题库原始选项顺序；如页面重新排列选项，应以答案文字为准。排序按题干的明确约束检查，约束仅适用于该排序题，不扩大为所有自然中文的唯一语序。

### 自由翻译参考与自然变体

#### l11-s2-translation-free-01

**越语题干：** Bố tôi đang tìm điện thoại.

**参考表达：** 我爸爸正在找手机。 / 我的爸爸在找手机呢。 / 我爸爸找手机呢。

**反馈重点：** 保留爸爸、找手机及进行中的意义；我爸爸／我的爸爸均自然。在／正在＋找与找手机呢均可。这里不要求给手机增加“我的”，越语未限定手机属于谁。

**依据：** 印刷 79, 82 / PDF 94, 97。

#### l11-s2-translation-free-02

**越语题干：** Ngày mai bạn có đi siêu thị không?

**参考表达：** 你明天去不去超市？ / 明天你去超市吗？ / 你明天去超市吗？

**反馈重点：** 完整表达“你／明天／去超市／是非询问”。自由翻译不限定必须使用正反问；吗问句同样完成交际任务。时间可置于主语前或后。

**依据：** 印刷 80, 83 / PDF 95, 98。

#### l11-s2-translation-free-03

**越语题干：** Em trai tôi định đi mua trái cây.

**参考表达：** 我弟弟要去买水果。 / 我的弟弟想去买水果。 / 我弟弟想买水果。

**反馈重点：** 表达弟弟与买水果的打算。要与已学的想＋动词都可表达合理意图；若省去去，购买意图仍正确，可由教师反馈出行信息是否完整，而不由网页扣分。

**依据：** 印刷 83, 84 / PDF 98, 99。

#### l11-s2-translation-free-04

**越语题干：** Tôi đang học đại học.

**参考表达：** 我在读大学。 / 我读大学呢。 / 我正在读大学。

**反馈重点：** 把大学学习表达为读大学即可；在／正在／呢的自然组合均可。根据上下文，我读大学也可表达现有身份，不因缺少正在而机械判错。

**依据：** 印刷 81, 82 / PDF 96, 97。

#### l11-s2-translation-free-05

**越语题干：** Anh ấy không ngủ mà đang đọc sách.

**参考表达：** 他没在睡觉，在读书呢。 / 他没有睡觉，正在读书。 / 他没睡觉，读书呢。

**反馈重点：** 前半句否定睡觉，后半句肯定正在读书。可用没／没有／没在，允许呢省略；不要求增加未教的而是。若写他不睡觉，需结合语境判断是否成了惯常不睡或不愿睡。

**依据：** 印刷 82, 83, 84 / PDF 97, 98, 99。

#### l12-s2-translation-free-01

**越语题干：** Tôi bị ốm rồi.

**参考表达：** 我生病了。 / 我病了。

**反馈重点：** 两种均在本课语言范围内，表达说话人的新病情。不能因为学生用病而非生病就视为缺词；不要求写具体病名。

**依据：** 印刷 89, 91 / PDF 104, 106。

#### l12-s2-translation-free-02

**越语题干：** Bây giờ mười giờ rồi.

**参考表达：** 现在十点了。 / 十点了。

**反馈重点：** 核心为十点及已到这一时刻。现在十点了最完整；在当前时间明确的语境中十点了也自然，可提示现在对应bây giờ，但不机械视为时态错误。

**依据：** 印刷 88 / PDF 103。

#### l12-s2-translation-free-03

**越语题干：** Bạn hãy uống một chút nước nóng.

**参考表达：** 你喝一点儿热水吧。 / 喝一点儿热水吧。 / 你喝点儿热水吧。

**反馈重点：** 礼貌建议可用句末吧，主语你可自然省略。一点儿／点儿均可表达少量；本课不要求尚未正式学习的请。只检查语言任务，不把句子写成医疗建议。

**依据：** 印刷 88, 91 / PDF 103, 106。

#### l12-s2-translation-free-04

**越语题干：** Anh trai tôi đến công ty rồi.

**参考表达：** 我哥哥来公司了。 / 我哥哥到公司了。 / 我的哥哥到公司了。

**反馈重点：** 表达哥哥到达公司后的新情况；来取决于说话人视点，到不需要该视点。越语đến本身未限定来／去，允许两种自然到达表达，不能强迫只有来。

**依据：** 印刷 88, 89 / PDF 103, 104。

#### l12-s2-translation-free-05

**越语题干：** Thời tiết hôm nay đẹp quá!

**参考表达：** 今天天气太好了！ / 今天的天气太好了！ / 今天天气真好！

**反馈重点：** 表达今天的天气很好及感叹。太好了为本课目标；真好也自然且此前已学，可另提醒本课句型练习机会。越语天气đẹp通常译天气好，不能逐词要求漂亮。

**依据：** 印刷 88, 90 / PDF 103, 105。

### 自由翻译参考与自然变体

#### l13-s2-translation-free-01

**越语题干：** Xin cho tôi hai cốc trà.

**参考表达：** 请给我两杯茶。 / 请给我两杯茶吧。 / 给我两杯茶吧。

**反馈重点：** 保留接收者我、两杯及茶。请／句末吧可以实现自然请求；以两而非机械逐字二杯为本课反馈重点。不要因主语省略扣分。

**依据：** 印刷 99, 100 / PDF 114, 115。

#### l13-s2-translation-free-02

**越语题干：** Tôi có thể gọi điện thoại ở đây không?

**参考表达：** 我可以在这里打电话吗？ / 在这里，我可以打电话吗？ / 我能在这儿打电话吗？

**反馈重点：** 请求许可语境下可以与能均可能自然，不能把能直接判错。地点这里／这儿可换；地点在主语前或后可接受。句末要保持询问意义。

**依据：** 印刷 97 / PDF 112。

#### l13-s2-translation-free-03

**越语题干：** Tôi muốn xem qua cuốn sách này.

**参考表达：** 我想看一下这本书。 / 我想看看这本书。 / 这本书，我想看一下。

**反馈重点：** 表达想、这本书及短时查看。看一下／看看均自然；看看有第12课语块依据。话题前置这本书在自由翻译中可接受，排序的题干限制不延伸到这里。

**依据：** 印刷 91, 97 / PDF 106, 112。

#### l13-s2-translation-free-04

**越语题干：** Cửa hàng này có bán sữa không?

**参考表达：** 这个商店卖牛奶吗？ / 这个商店卖不卖牛奶？ / 这家商店卖牛奶吗？

**反馈重点：** 表达这家／这个商店是否出售牛奶，吗与卖不卖均可。家作商店量词已在第9课出现，可接受；不要因使用吗而要求改成正反问。

**依据：** 印刷 96, 97, 99 / PDF 111, 112, 114。

#### l13-s2-translation-free-05

**越语题干：** Người phục vụ đưa cho chị gái tôi một cốc sữa.

**参考表达：** 服务员给我姐姐一杯牛奶。 / 服务员给我的姐姐一杯牛奶。

**反馈重点：** 施事是服务员，接受者是我姐姐，事物是一杯牛奶。的可省；主宾角色和一杯数量需保留。本句未给过去语境，无须强制学生增加了。

**依据：** 印刷 98, 99 / PDF 113, 114。

#### l14-s2-translation-free-03

**依据：** 印刷 105, 107, 108 / PDF 120, 122, 123。

#### l14-s2-translation-free-04

**参考表达：** 我女儿明年上中学。 / 明年我的女儿上中学。 / 我的女儿明年上中学。

**反馈重点：** 完整表达女儿、明年与上中学。明年已能表达未来，无须另加尚未作为目标义教学的会；有无的均可。按教材中学译trung học，不要求特定年级。

**依据：** 印刷 109 / PDF 124。

#### l14-s2-translation-free-05

**反馈重点：** 下班了与下了班在此均能自然报告下班，前者句末新情况、后者动作发生的侧重可有差异。教师可说明差别，不把较常用的下班了判错以强迫离合拆分。

**依据：** 印刷 105, 106 / PDF 120, 121。

### 自由翻译参考与自然变体

#### l15-s2-translation-free-01

**越语题干：** Tôi thích uống trà và cũng thích ăn bánh mì.

**参考表达：** 我喜欢喝茶，也喜欢吃面包。 / 我喜欢喝茶，还喜欢吃面包。

**反馈重点：** 也／还均可自然连接同一主语的两种喜好。两项分别是喝茶、吃面包，不能只机械重复喜欢而漏掉一种喜好；不要求额外主语，重复我也可。

**依据：** 印刷 113, 114 / PDF 128, 129。

#### l15-s2-translation-free-02

**越语题干：** Ngày mai chị gái tôi sẽ đón bạn ở sân bay.

**参考表达：** 我姐姐明天在机场接你。 / 明天我姐姐在机场接你。 / 明天我的姐姐去机场接你。

**反馈重点：** 表达明天、姐姐、机场、接你。可采用在机场接你或去机场接你。明天已表达未来，无须强制加会；若学生自然使用会，只就其语境解释，不把本题变成新义测验。

**依据：** 印刷 117 / PDF 132。

#### l15-s2-translation-free-03

**越语题干：** Đi đến sân bay mất ba giờ.

**参考表达：** 去机场要三个小时。 / 到机场要三个小时。

**反馈重点：** 用要表示所需时长，三个小时为时间段而不是三点。去机场／到机场均自然。本句只是虚构练习，不据此判断现实路线。

**依据：** 印刷 117 / PDF 132。

#### l15-s2-translation-free-04

**越语题干：** Năm ngoái bạn trai tôi sống ở Tây An.

**参考表达：** 我男朋友去年住在西安。 / 去年我的男朋友住在西安。 / 我男朋友去年住西安。

**反馈重点：** 表达男朋友、去年、西安及居住。住西安／住在西安均自然，时间可前后。过去居住状态不强制加了；不能把越语时间信息逐词等同汉语体标记。

**依据：** 印刷 115, 117 / PDF 130, 132。

#### l15-s2-translation-free-05

**越语题干：** Mọi người trong gia đình tôi đều sống ở Bắc Kinh.

**参考表达：** 我的家人都住在北京。 / 我家人都住北京。 / 我家人都住在北京。

**反馈重点：** 保留家人范围、都及北京居住。我的家人／我家人均可；住在北京／住北京也可。若写我家人都在北京只报告所在地点，可反馈缺少明确居住义，但不由网页自动判。

**依据：** 印刷 117 / PDF 132。

## 统一反馈边界

- 对含义完整、中文自然但与样例不同的表达，先接受交际成果，再指出本课可练习的句式。
- 对遗漏数量、人物角色、时间或动作的表达，给出具体反馈；不要只写“跟答案不一样”。
- 不要求每句有了、每个đang有正在，也不要求未来一律用会。
- 第11课饭店按餐馆解释；第15课爱按饮食喜好解释，避免只看词形套用别的义项。
- 教师可以根据实际教学对自由翻译补充反馈，但网页保留的原始提交和截图证据不应被参考答案覆盖。
