# HSK1 第二步：15课、225项作业

本步依据用户确认的四步方案，从第一步已验收的第3课样板扩展到全部15课。新增其余14课210题，并对全225题进行教材范围、中文表达、越南语题意、选择题唯一性和排序合理变体审校。第3课获批题库逐对象保留。

## 本步范围

| 内容 | 每课 | 全15课 |
|---|---:|---:|
| ABCD单选，提交后评分和解析 | 5 | 75 |
| 词块组句，提交后评分和解析 | 5 | 75 |
| 越南语译中文，由老师评阅 | 5 | 75 |
| 全部作业 | 15 | 225 |
| 自动评分题 | 10 | 150 |

选择→组句→越译中，每组完整作答并提交后开放下一组，没有正确率门槛。不同课程可自由选择。首答和最近一次成绩分开保存，重做不重新锁住后面的组。翻译只检查是否填写，保存学生原文，不显示正确/错误、分数或参考译文。

教材是用户本次上传的《新HSK教程1》，对应第一步 `course-map.json` 中15课。题型参照本册交际情境和练习，新增题为本项目编写，不称为教材官方原题或官方答案。题目页码采用教材印刷页；PDF物理页为印刷页+15。每题记录两种页码。

第三步的独立听力、75道听力题、混课生词及复习功能，第四步的全站整合和最终交付，继续按已确认顺序执行。本步保留第一步样板及生产页面，不调整正式音频、课文对齐、访问口令或旧进度键。

## 可运行版本

`dist/stage2/HSK1-Step2-All15Lessons.html` 是包含225题、样式和脚本的单文件，可在支持JavaScript的浏览器打开。手机文件预览器若不执行脚本，需要用浏览器打开。该审阅版独立运行；正式访问控制在第四步整合时接入。

从仓库重新生成并预览：

```sh
node tools/build-stage2.cjs
node tools/serve-stage2.cjs
```

预览服务在端口8766，只提供本步页面的文件白名单，没有仓库目录浏览、教材上传文件或认证脚本。每课可通过页面上方15个课次按钮切换。链接末尾的 `#lesson=3&part=choice` 记录当前课与题组；请求未解锁的题组会回到可作答部分。

## 译文截图与备份

每课翻译提交后，截图页显示该课课名、5个越语题目、学生原样中文、姓名/班级和提交时间。可打印或保存PDF。网页没有发送给教师的服务，学生自行截图发送；“已保存”不表示老师已收到或批改。

本步使用独立进度键 `ran_hsk1_stage2_v3`，不会自动读取或改写正式旧版、第一步的键。用户可通过选择JSON文件或粘贴文本显式导入。第一步第3课记录在内容匹配时恢复；旧v2翻译选择题不会算作自由翻译已提交。新编题使用新ID，避免把旧题成绩当成本题成绩。

浏览器容量不足时保留当前内存作业并提示下载备份；打开另一备份前保留上一版，若浏览器无法存下恢复副本，则明确提示它只在当前标签页有效。同一浏览器的另一个标签更新进度时，本页暂停自动覆盖，保留当前草稿供导出或检查最新版；本步没有跨设备账号同步。

## 文件索引

- `new-hsk1/hsk1/stage2/question-bank/`：三组JSON，按1–5、6–10、11–15课划分；`bank.js`由构建脚本生成。
- `content-01-05.md`、`content-06-10.md`、`content-11-15.md`：逐题目标、教材页码、语义或词序边界。
- `teacher-reference.md`：全15课教师参考汇总，含150道客观答案和75道人工翻译参考；三个 `teacher-*.md` 分册保留详细评阅提示。学生网页不加载这些文件。公开仓库中的文档分离不是教师权限系统。
- `curriculum-review.md`：课程范围、已知教材差异和审阅版本绑定。
- `independent-review.md`：独立题目与状态逻辑审查。
- `test-report.md`：本次已完成的21项引擎测试、25个浏览器步骤、全部225题界面操作、截图与制品一致性证据。

## 验收要求

全15课均须实际完成选择、组句、自由翻译三组，检查课内解锁、课间隔离、提交后越语解析、首次/最近成绩、各课截图标题与原文。另检查漏答、重做、刷新、备份导入、第一步恢复、旧v2迁移、长文本、手机宽度、跨标签写入保护和独立HTML。

规则测试不代替题目语义审校；浏览器桌面/窄屏视口测试不代替实机输入法或所有浏览器认证。最终报告只记录已经实际执行并取得证据的检查。
