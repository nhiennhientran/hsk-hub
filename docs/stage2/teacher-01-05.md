# 第1—5课教师参考（第二步）

每课15项作业中，5道选择和5道排序自动评分；5道越译中由教师评阅，网页不自动判对错、不评分。首次成绩与重做成绩分别保存。以下选择题字母按题库原始顺序，界面若打乱选项，应按题目ID和答案文字核对。

参考译文用于判断意思和表达，不作为逐字匹配规则。可接受自然的呼语位置、并列顺序、时间位置、数字写法、已学人物关系中省略的等情况。老师可分别提示核心意义、句法和汉字书写问题；学生页面只记录提交。
