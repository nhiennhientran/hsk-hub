# Phase 2 engineering checkpoint package

This is an internal DRAFT engineering candidate. It is not a release authorization or a 48-lesson semantic acceptance certificate. Official VI registries must remain inactive. The final release gate is neither rewritten nor bypassed.

From `course-app`, after committing the intended candidate and installing both apps' locked dependencies:

```sh
HSK_PHASE2_BROWSER=chromium node docs/continue-phase2-20261005/package/build-checkpoint.mjs
```

Use the actual CI matrix browser (`chromium` or `webkit`). All reports, logs and generated bytes go to `.repro-output/continue-phase2/$HSK_PHASE2_BROWSER/package/`; an existing directory is rejected. Build logs retain the real command exit codes and SHA-256 identities. The root CI recorder separately binds the complete engineering/test/workflow source scope and installed native browser to the actual GitHub checkout.
