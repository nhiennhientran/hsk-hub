# HSK3 optional pinyin context evidence

HSK3 running text is not printed with pinyin in this edition. Website sentence pinyin is editorial and defaults off; printed vocabulary pinyin remains source-derived. Each lesson received an independent contextual pinyin review. This final targeted pass adds regression snapshots for contrasting readings rather than relying on one default pronunciation per character.

A broad short-word scan found155 text lines containing potentially context-sensitive characters. That is a candidate count, not155 certified errors or an independent full human pronunciation audit. The following14 selected contexts were read together with their independently verified Chinese source and stored as immutable source/pinyin guards. No pronunciation corrections were needed in these cases.
