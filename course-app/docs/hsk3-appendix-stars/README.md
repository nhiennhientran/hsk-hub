# HSK3 appendix star reconciliation

The textbook star legend (PDF186, printed174) and Chinese glossary PDF187–194 were visually inspected; the22 starred headwords map to23 existing word-sense records. An independent second review confirmed the stars and source pages. This patch adds two existing metadata properties to16 previously unmarked records. Seven records already carried the flags.

Removing just these32 properties restores every original lesson byte. No wording, pinyin, POS, audio ID, lesson/activity ID, question fingerprint or homework content changes. This is not a claim that every ordinary glossary/POS/English entry has been checked.
