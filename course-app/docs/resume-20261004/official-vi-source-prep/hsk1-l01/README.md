# HSK1 第1课：官方越文原页作者转录

仅据本次官方越文 PDF 原页视觉转录；本任务没有读取网站越文作比较，也没有改运行内容、B10 源码或任何已冻结测试。独立原页审查尚待另一位审查者完成，不能把作者结构检查当作译文验收或 active 修订。

源 PDF SHA256：`99ca3e635bbf99bcbbe003e32a0dbdf7ad0af2300b7380959d647e1028cf2764`，148 页。实 PDF17–20 对应印刷001–004；下一课从实 PDF21/印005开始。这些位置已依据开篇和实际 footer 视觉确认。

source-transcription.json 共 67 个独立印刷 VI 出现项：PDF17 为14项、PDF18 为27项、PDF19 为18项、PDF20 为8项。完整覆盖课标和标题、2项目标、3篇场景、10条分角色译行、12条普通词释义、1条专名释义、10条实际 POS、所有可见指令及表/节标题、2条小语提示、2条绕口令译行、视频标题/主题及页眉。重复的标题、指令和提示标签逐次保留，67是出现项，不能称67个唯一语义译文。

排版折行在 fragments.lineTexts 保留，viText 用单空格连接；本课没有越文正文跨页的合成片段。原印 `khoá`、`khoẻ`、`htố.` 和省略号拼写忠实保留，不做新版拼写或 raw POS 分类替换。你好、不客气的词表行没有原印 POS，记录 null，不补造标签。普通词/专名词表另有13行完整编号、中文、拼音及出现项绑定。中文/PY对话主气泡的VI来自同页独立译文框；头像中文角色名、AI生成合成标识、视频黑板中文/PY及播放器图标没有本位置额外 VI，明确不编造。

四张完整页图为2.5×原 PDF 点尺寸。PDF18词表及PDF20小语提示另有4×裁剪，矩形、渲染版本、每张 SHA/bytes 均在 render-manifest.json。PNG不是OCR文字替代品，独立审查应直接阅读这些原页和必要的同源裁剪。本课未发现需报告的明显教材内部矛盾；candidateErrata 为空不等于语言内容已经独立通过。

在本目录执行：

```bash
python verify-transcription.py
python render-source.py --pdf '/path/to/HSK1  (3.0).pdf'
```

前者只核结构、唯一ID、fragment连接、源页引用和实际图 SHA；后者默认只读重渲染，要求相同 PDF SHA、148页和已记录 PyMuPDF 版本，逐PNG字节复验。作者生成模式额外加 --write。freeze-manifest.json 冻结本课所有转录、原页图、脚本和作者检查日志；不包含原 PDF 本体，不自签独立 accepted。
