# Durable recovery resume protocol

All Git writes belong to the one checkpoint owner. Authors and reviewers never stage, commit or move refs. Never change main or gh-pages, never deploy before the user's final approval.

Read the latest actual Git refs for work/hsk-source-recovery-20261005 and work/hsk-recovery-text-shield-20261005. The two branches deliberately separate complete frozen evidence from early original text protection. Only a successful immutable RAW-download receipt proves exact preserved bytes; object creation, a prepared capsule, or an author self-check cannot prove complete source acceptance.

CURRENT-PROGRESS.json is an as-of snapshot. Reconcile later immutable receipts before reporting current counts. Do not count source repair-required V1 reviews as complete accepted lessons. H3 lesson11 V2 requires the complete V1 fresh-reading package and the author V2 package to be exactly saved; H1 lesson12 and later shared appendix reading relies on H1 lesson11 full evidence. Shared appendices repeat physical source items and cannot be counted as fresh unique items in every lesson.

The latest tooling snapshot contains DURABLE-QUEUE.json and exact copies of each scope capsule. Its savedCapsulePath is repository relative and remains valid after Scratch is replaced. Original absolute helper/capsule paths are historical observations, not proof that the old temporary paths still exist. Rebase helper paths and module ROOT / HELPER constants into the actual recovered checkout before executing scripts; regenerate each prepared capsule against its current local parent before staging. Never rewrite an author/reviewer frozen package.

Create any future text shield through its own GIT_INDEX_FILE and commit-tree. This preserves the normal full-sync HEAD and index. The uploader reads committed blob objects and asserts exact Git SHA. Full finalizer creates a remote tree equal to the local complete tree, moves only the chosen work ref with force false, and verifies ref / commit / parent / tree and protected production heads. Then download every capsule path from the immutable remote commit and compare bytes, SHA256, and Git blob SHA. Record actual all-path success before upgrading saved status.

Source transcription fidelity is distinct from website Vietnamese alignment, consumer coverage, trusted runtime activation, and release approval. No recovery package establishes those later claims.
