# HSK2/3 content contract

The two new editions share one engine. The legacy HSK1 runtime stays deployed byte-for-byte. Course identity is `hsk2-fltrp-2026` or `hsk3-fltrp-2026`; content version is `2026.1`. Lesson IDs are canonical strings such as `hsk2-fltrp-2026:l01`; no existing legacy lesson number is a migration key.

Each lesson is a JSON file in `content/hsk2/lesson-01.json` or `content/hsk3/lesson-01.json`. Source pages are the one-based PDF page (printed page +15 for HSK2, +12 for HSK3). Every source-derived object carries `source: {pdfPage, printedPage, section, provenance: "textbook"}`. Supplemental original teaching text and questions use `provenance: "supplemental"` and reference the corresponding source page/section. Never claim supplemental examples or Vietnamese translations were printed in the source. No raw book image or answer package is published.

## Lesson shape

- `schemaVersion:1`, `courseId`, `version:"2026.1"`, `number`, `id`, `title:{zh,py,vi}`, `source:{startPdfPage,endPdfPage,startPrintedPage,endPrintedPage}`, `reviewStatus:{sourceVisual:boolean,vietnamese:boolean,pinyin:boolean,reviewer:string,notes:string[]}`
- `objectives:[{id,zh,vi,source}]`
- `warmup:[{id,title:{zh,vi},items:[{zh,vi}],source}]`
- `texts:[{id,number:1..4,title:{zh,vi},context:{zh,vi},audioTrack:"1-1",lines:[{id,speaker,zh,py,vi,source}],questions:[{id,zh,vi,options?:string[],answer?:number,source}],source}]`. Exact Chinese text and speaker attribution, corrected from pixels; translation and optional HSK3 pinyin are editorial supplements. Odd audio tracks map to texts; even tracks map to each text's printed vocabulary list.
- `vocabulary:[{id,zh,py,vi,pos,sourceText:1..4,audioTrack:"1-2",source}]`. Distinct word-senses have distinct IDs; do not equate syllabus counts with this real count. Vocabulary audio means the original full list, not a guessed single-word cut.
- `grammar:[{id,title:{zh,vi},structure,explanation:{zh,vi},examples:[{zh,py,vi,source}],practice:[{zh,vi,source}],source}]`. HSK2 exactly 3 points per lesson; HSK3 count as inventory.
- `sections:[{id,kind:"practice"|"activity"|"culture"|"tip"|"review"|"other",title:{zh,vi},blocks:[{kind:"paragraph"|"instruction"|"question"|"example"|"table",zh,vi,items?:[{zh,vi}],source}],source}]`. Preserve integrated exercises, classroom activities, culture/learning columns where printed, and 3-lesson reviews. Culture panels are not mandatory in every lesson: HSK2 lesson4 has none (PDF44–51), and no filler may be invented. For image-only tasks, faithfully describe the task and image content rather than inventing or dropping it.
- `homework:[Question]`: exactly 30 original questions. 10 vocabulary/grammar choice, 5 ordering, 5 original-audio listening choice, 5 Vietnamese-to-Chinese choice, 5 manual Vietnamese-to-Chinese writing. Each question has `id`, `part:"vocabGrammar"|"ordering"|"listening"|"translationChoice"|"writing"`, `prompt:{zh,vi}`, optional `stem`, `options:string[]`, `answer:number` for auto-choice, `tokens:string[]` and `answer:number[]` for ordering, `audioTrack` for listening, `source`, `focus`, `explanation:{zh,vi}` for auto questions only. Writing focus labels must be neutral skill IDs or Vietnamese categories, never target Chinese answer chunks. Writing questions must have no answer, model answer, scoring key or solution in the published JSON. Their prompts are Vietnamese text plus a neutral Chinese instruction, with no answer leak. Store teacher-only writing references separately outside public content if needed. Ordering must have only one sensible expected order under the supplied context, include punctuation as anchored tokens or in the prompt. Listening questions must be answerable from the linked original track and not require TTS.
- `listening:[Question]`: independent audio-listening set per lesson, separate from homework and reachable from the lesson. Questions may target different comprehension points on original tracks, with explicit identity separate from homework.

Prefer complete, correctly grounded items over automatic quantity padding. Report source uncertainty as a blocker or review note; do not fabricate missing pages. All published content needs pixel validation. Validate JSON and section/count contracts before claiming a batch is complete. Keep content audit evidence in `docs/content-audit/` with pages viewed and any corrected OCR errors.

## Final lexical-identity closure

Before release, materialize and independently review a canonical word-sense catalogue for each edition. Lesson-local word IDs retain page/word-list provenance; shared sense IDs must explicitly distinguish POS and meanings and document repeated-sense merges. Do not let Vietnamese wording differences accidentally create two study senses, or merge homographs merely because Chinese spelling matches. The current exact-signature practice grouping is a pilot mechanism; full-edition sense closure is a phase10 release gate.

The final catalogue lives in `content/hsk2-lexicon.json` and `content/hsk3-lexicon.json`. Each stable `course:sense:lesson-word` ID has explicit lesson-local source IDs, page/POS/pronunciation/meaning bindings, and a reviewed same-spelling decision ledger. A repeated sense may merge only through an explicit reviewed merge record; translation-string differences alone never decide identity. Saved practice queues retain their existing new-edition lesson-local IDs, while canonical sense IDs govern grouping; this does not migrate any legacy course data. Card backs show Vietnamese POS to distinguish same-form grammatical uses. Course totals are labeled sense cards, not advertised syllabus vocabulary targets.

`draft-lexicon.mjs` creates unreviewed draft catalogues and refuses to overwrite a reviewed catalogue. `verify-lexicon.mjs` gates full release on independent review, complete coverage, exact source bindings, same-form decisions, and reviewed merges. Content manifests freeze the catalogue SHA256 values alongside lesson and original-audio hashes.
