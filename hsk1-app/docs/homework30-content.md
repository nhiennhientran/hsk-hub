# HSK1 30题作业内容冻结：hsk1-homework-30-v1

## 数量与边界

15课各30题，共450题。分组不能通过增加隐藏入口、重复旧题或扩展题突破配额。

| 分组 | 每课 | 全课程 | 评估 |
| --- | ---: | ---: | --- |
| choice：词汇／语法选择 | 10 | 150 | 自动 |
| sort：排序 | 5 | 75 | 自动 |
| listening：听力选择 | 5 | 75 | 自动 |
| translationChoice：越译中选择 | 5 | 75 | 自动 |
| translation：越译中自由书写 | 5 | 75 | 人工，不含答案 |

自动题共375题，其中300道选择题、75道排序题。75道人工书写题不进行标准字符串判分。初级课的越译中选择包含词语／称呼选择，不能把它们宣传成全部为完整句翻译。

本交付只负责内容、来源、去重／泄漏复核及测试。旧成绩、存储、UI、发布等验收由对应模块负责，不把本内容测试当成全部应用验收。

## 最终交付与检查入口

- `content/homework30-bank.json`：实际450题；根字段为 `schemaVersion`、`version`、`lessons`
- `docs/homework30-mapping.json`：450条权威映射、原题／目录入口ID与指纹、新版修订身份、完整未选维护清单
- `docs/homework30-inventory.json`：450题逐题清单，含课号、题型、题干、能力目标、来源及内容指纹；不含书写参考答案
- `docs/homework30-content-audit.json`：逐课覆盖、191项新版修订的中越说明／干扰项理由／教学范围证据、160项初审问题的具体处置、完整跨课字串及人工题暴露扫描结果
- `docs/homework30-review-cases.json`：初审问题输入，绑定被否决的初稿指纹；它是历史问题清单，不是对旧43组重复的自动豁免
- `tools/homework30-content.mjs`：组装及复现生成器
- `tools/homework30-revisions-early.mjs`、`tools/homework30-revisions-late.mjs`：新版专用情境修订；不写旧来源
- `tools/homework30-review.mjs`：修订材料化、原目标／新目标分离、教学范围引用
- `tools/homework30-evidence.mjs`：全量重复、完成填空、跨课及人工题暴露证据生成
- `tests/homework30-content.test.mjs`：16项正向与失效注入测试

## 来源选择与新版修订不是同一件事

基础映射仍从旧作业225题及综合目录225个入口组成。每课原有5选择、5排序、5自由书写仍各有明确来源引用。补充来源通常为原综合5选择、5听力、5越译中选择；第三课原综合5选择和旧作业共用同一核心，因此改从5个原综合排序入口建立明确的语法新编来源关系。

最终不是把这些来源直接复制450次。独立内容复核发现原初稿存在同义／重排重复、只换姓名数字的重复情境，以及错误选项、转写和说明直接暴露人工题答案的问题。因此在不改旧来源的前提下，新版应用191项明确修订：

| 修订类型 | 数量 |
| --- | ---: |
| 词汇／语法选择 | 70 |
| 排序 | 31 |
| 越译中选择 | 68 |
| 人工书写题干 | 22 |
| 合计 | 191 |

另有先前已明确记录的第三课5道独立语法情境。这5题分别考照片身份询问、持续工作状态、姐姐的老师这一领属关系、纠正女朋友关系误认、想念关系中的主宾方向，不再把保留排序的相同句子换成选择题。

所有75道听力的原轨、起止秒、中文转写和拼音保持来源原样。没有为了去重改写录音内容或给原音配上不相符的新转写。第10课第4听力继续保留已校正的“我想买两斤苹果。”。

每项修订在审计中分别保存：

- 不可变的原题核心、原目标、原题干及来源指纹
- 新版目标、情境变化、明确改变的字段及修订指纹
- 四个选择项各自的正误理由，或排序词块／认可表达的语法理由
- 当前课或更早课的实际词汇、语法、课文记录ID与指纹
- 人工题只保存意义保持要求和一般评分准则，不保存中文参考答案或可接受答案列表

这使“保留历史来源和旧身份”与“修正新版语境”可独立核查，不能把原来源指纹误称为新编答案的逐字依据。

## 去重与泄漏的最终规则

初稿仅检查完整选择题相等及43组中文片段，不足以证明内容不重复。最终复核扩大到全部450题，使用以下证据：

1. 跨课比较选择题题干、显示题干、无序选项集合及正确选项；换选项顺序不能隐藏同一道题
2. 重建填空后的完整句子；同时比较正确选项、所有显示题干、排序认可表达及听力分句
3. 全部75道人工作文题干与375道自动题的题干、意义、选项（包括错误选项）、解释、逐项反馈跨课对比
4. 对同义改写、只换姓名／数量／地点的情境、中文对应表达及人工答案可能的自然变体作独立语言复核，不能用字串计数代替此项
5. 每个历史问题都明确指向实际修改的题号及实质变化，不以“题型不同”或“本课改过其他题”为默认处置

最终精确扫描结果：

- 完整选择题重复记录：0
- 未经具体理由复核的中文片段重复组：0
- 越文人工题完整命题出现在自动题任何扫描字段中：0
- 同课仍有2个必要的词汇复现组，另有1个有具体教学理由的跨课复现组

仅保留以下三项明确例外；匹配绑定具体题号，不能自动扩展到新题：

- 第12课 `choice-02` 与 `choice-09` 的“有点儿”：前者识别形容词前的程度；后者在两个不同句法槽中对比程度“有点儿”和名词数量“一点儿”，不是重复翻译相同句子
- 第12课 `choice-03` 与 `choice-09` 的“一点儿”：前者识别名词前的小量；后者要求区别数量与程度两类用法
- 第11课 `choice-08` 与第13课 `listening-02` 的“我不知道”：前者辨认信息未知状态；后者在原音的完整回应中还须理解“打电话问一下”的建议，属于后续课对已学表达的具体复用

第一课词汇范围很小，基础问候、感谢、告别中的单字和短语不可避免复现。新题区别称呼对象、交际功能、词语角色、语序或多个言语动作的组合；没有保留旧的五个单短语写作答案，让其他题直接提供整份书写作业答案。不能把这种受限词汇练习宣传成30个互不相关的语言概念。

## 语言准确性与教学范围

191项修订均附逐题范围引用。引用必须实际存在、指纹相符，且课号不晚于目标题。教学记录展示已教构件；它不是声称“词汇出现过就证明任何新句法都已教过”。新情境另复核中文自然度、越文准确性、正确项唯一性及干扰项理由。

最终处理包括：去掉提前出现的“杯”量词、“都”、“一起”和未有依据的“是……的”焦点句；将不必要的嵌入问句改为独立的已学句子；澄清“朋友的书”不是越语含混的“你的书”；将“一件衣服”一致译为一件／一项衣物，不夸大为一整套服装；第4课量词错误项仅说明第二空不能以“口”数课堂学生，不虚构“个不能数家人”的规则。

人工题按完整意义及任务要求评阅：人物与角色、时间、肯否、数量、所需言语动作都必须保留；允许自然的已学词序和同义表达。若题干明确要求某种问句形式，评阅须检查该要求。所有这些属于一般评分准则，没有向学生源码、前端包或公开维护文档加入标准答案或逐字答案变体。

本次是自动校验与独立辅助内容复核，不宣称母语教师认证、课堂验证、再次逐段人工听审或重新逐页核查教材PDF。

## 来源、身份和指纹

新ID固定为 `hw30-v1-lNN-{part}-NN`。`translationChoice` 的 `kind` 为 `choice`，`listening` 的 `kind` 为 `listening`，只有自由书写使用 `assessment: manual`。

题目 `fingerprint` 是除自身之外所有字段的SHA-256：对象键递归排序、数组保留顺序。`provenance.sourceFile/sourceId/sourceFingerprint` 指向实际不可变题目核心。综合目录的入口ID、入口指纹、旧ID、共享 `authorityId` 和入口覆盖另外记录，不把入口与答案核心混为一谈。

新版修订使用 `transformation: reviewed-distinct-scenario-v1` 及 `revisionFingerprint`。源教材页码可作为学习内容出处保留，但标签明确为新版情境；没有实际页码的历史代码来源始终使用空 `printPages/pdfPages`，不伪造教材页码。

191项修订不会改动原文件、旧ID或原指纹，也不声称旧成绩就是新情境的成绩。成绩边界由版本化运行模块另行验证。
