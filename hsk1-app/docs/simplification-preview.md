# HSK 1 简化学习流程预览

这是独立预览分支的后续优化，尚未获得本轮正式发布批准。生产恢复版本的证据仍在 `legacy-restoration-production.md`；不能把它的通过结果当作本轮验收。

## 学生入口

主导航现在只有四组：课程 / Bài học、课后作业 / Bài tập、练习与复习 / Luyện & ôn tập、进度 / Tiến độ。`src/app/navigation.ts` 只管理显示分组；`FEATURES`、单一路由和历史URL仍保留各自身份。

- 课程卡默认显示课名、简要状态和一个进入链接；“查看各部分”展开五个教材部分、当前作业和独立听力。全部15课仍自由开放
- 新作业入口显式带 `version=30-v1`。每课严格30题，25自动评分与5教师批阅分开；旧版15题记录不会换分母或移入新成绩
- 练习与复习是词卡、独立听力、教材自练的入口。它不复制队列或分数；旧复习词卡的“继续”解析到真实保存的词卡位置
- 教材检索/批量工具、下一轮词卡/听力设置、统计、可选姓名/班级和数据工具分层展开。设置下一轮不会替换当前轮；开始按钮才创建新轮
- 词卡上一张、下一张、跳过仍自由；跳过不算掌握，自评只用于复习安排。教材星标、自动分数、人工写作和自评均为不同领域
- 老综合练习/pilot/作业复习URL进入只读历史。仅展示本范围已有作答/草稿，未做过的题不会形成额外学生题库；不能在此重做、评分或开新轮
- 数据管理是进度中的可返回面板。重置需先明确选择课次与领域，预览再确认；不预选“全部课+全部模块”

## 内容和历史边界

新增 `content/homework30-bank.json` 是有版本的新评估。源文件 `stage2-bank.json`、`stage3-catalog.json`、`legacy-exercises.json`、`textbook.json` 和旧作业引擎保持原字节。新情境题、来源复用、实质变化和未选题的维护归档均有独立映射，不改旧记录ID或指纹。

权威说明见 `homework30-versioning.md`、`homework30-mapping.json`、450题清单 `homework30-inventory.json` 和内容复核 `homework30-content-audit.json`。重复检查必须覆盖同课的题干/完整填空、选项、正确答案、解释、排序解和听力转写，以及人工题的语义；字段白名单和字符串不同都不等于不会泄露后续写作答案。

人工写作没有自动参考答案或自动正确率。教师可能接受的变体应由教师审阅；不要把教师参考译文放进公开学生源码、JSON、说明或source map。

## 小型共享UI与维护

- `src/app/ui.ts`：安全DOM节点、双语链接、原生展开面板；不承担评分和存储
- `src/app/bilingual.ts` / `bilingual.css`：中文主标签、越文副行，保留语言标记、可读字号和正常换行
- `src/app/styles.css`：统一翠绿/金色视觉、间距、按钮、对比度与焦点。金色用于装饰，浅色表面焦点使用深绿
- `src/features/progress/summary.ts`：当前作业和明确标注的旧版历史分开投影；原领域的已有指标ID保留供历史回归检查
- `src/features/exercises/archive-data.ts`：只读历史投影，不创建新提交、回填分数或排序原时间

不要为减少按钮重写音频服务、学习store、路由、学习规则或引入新的框架。纯展示状态留在DOM；不要为展开面板新增持久化格式。新内容的语义修订在未发布版本中完成；已发布后不得仅改指纹来冒充兼容。

## 最终验收流程

1. `node tools/homework30-content.mjs --check`、`catalog:check`、`fixtures:check`、`index:check`、`check`、全部单元测试
2. `build:release`、公共产物/媒体/来源与结构校验；现仓库没有独立ESLint配置，不能把未执行的lint称为通过
3. 既有GitHub预览workflow只构建一次。Chromium和WebKit复用同一冻结制品，运行完整smoke与严格子路径release测试；早期截图失败不会阻止收集其他回归失败，但完整测试仍须通过
4. 检查320/390/768/1440宽度、中越标签、键盘、合成IME事件、非空旧记录、双版本备份/恢复/重置、重复/中断流程和原音
5. 下载同一次运行的截图和受测制品，核对清单哈希；最终文件改动后重跑，不用旧候选结果替代最终候选
6. 提供可运行预览包和真实截图供本轮确认；获确认前不合并或替换正式站

代码与模拟浏览器检查不代表人工逐题语言终审、真实听辨、实体iPhone/Android、系统输入法或设备中文语音已通过。这些限制必须如实标明。
