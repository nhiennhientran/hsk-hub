## 结构与保存

| 文件 | 责任 |
|---|---|
| `services/content/homework.ts` | 读取/校验唯一冻结题库，明确选择/排序/人工翻译类型 |
| `features/homework/controller.ts` | 作答、缺题校验、提交、解锁、重做及排序初次顺序；调用原纯规则 |
| `features/homework/index.ts` / `homework.css` | 越语交互、反馈、资料、状态及控件生命周期 |
| `features/homework/receipt.ts` / `receipt.css` | 只读首次/最近提交快照、原文布局及打印样式 |
| `services/learning/session.ts` | 应用持有的学习会话、300ms防抖、合并保存及最终flush |
| `services/storage/index.ts` | 原子容器与锁；新signal参数仅取消视图导入/恢复 |

没有新框架、通用组件系统、事件总线或新持久键。控制器只改变homework，听力/词汇/阅读数据保持独立。只读挂载、缺题和重复提交不写盘。应用懒加载一个存储实例，作业和数据管理工具共享当前内存稿；卸载页面清监听/请求并flush，不能dispose整份学习状态。数据管理的导入/恢复在排队前及取得锁后检查视图取消，离页不晚写。

保存等待锁时的新编辑进入该次保存；保存完成之后的新编辑才另写一次。失败保留原文并停止自动重试循环，可下载、明确重试；quota/禁止写入/冲突不能冒充已保存。损坏主记录仍保护原字符串。visibility隐藏与切页触发flush；浏览器强制关闭时仅尽力保存，以可见“已保存”或已下载备份为准。

翻译限制为12000 UTF-16代码单元，profile为200；原文不规范化，零宽/纯空白不能提交。组合输入中禁止提交、暂去maxlength防截字，结束恢复上限；过限保留DOM并提示未保存，不能偷偷提交旧稿。提交/收据/卸载前采集合法最终DOM值，特别覆盖最后尾字已显示但input尚未触发的情况。保存状态订阅只更新摘要，输入时不重建文本框/移动光标。
