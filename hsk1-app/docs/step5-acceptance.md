## 结构与维护

| 位置 | 责任 |
|---|---|
| `services/content/textbook.ts` | 读取唯一JSON，校验15课和媒体/义项关系，返回只读教材与明确缺音结果 |
| `services/audio/index.ts` | 应用持有一个Audio；原轨/片段/TTS互斥，代次隔离、范围停止、速度和可重试错误 |
| `services/learning/reading.ts` | 只编辑reading和教材继续位置，复用300ms自动保存与失败备份 |
| `features/textbook/index.ts` | 五节挂载、真实ready、导航、阅读与保存状态；退出清理并flush |
| `vocabulary.ts` / `text.ts` / `language.ts` | 各自负责教材内容及交互；公共播放器在`player.ts` |
| `hanzi.ts` / `services/hanzi/vendor.js` | 本地笔顺与动画/练写；固定3.7.3原库正文和必要销毁适配 |
| `domain/textbook/practice.ts` / `features/textbook/practice.ts` | 原练习纯生成/评分与独立页面状态 |
| `tools/course-assets.ts` / `check-course-assets.mjs` | 开发媒体范围请求、构建复制及独立字节/哈希验收 |

没有新增框架、运行依赖、事件总线、通用组件系统或第二套保存/播放器。视图通过signal拥有自己的播放请求；旧详情关闭或旧视图取消不能停止新请求。Audio的`play()`在用户操作中立即调用，收到真实`playing`才显示播放；旧Promise拒绝不能覆盖新状态。片段结尾核对实际duration，允许50ms编码差；首个播放/start事件前结束视为错误，不自动推进播放列表。

Hanzi Writer 3.7.3没有公开销毁接口，固定版本适配使用AbortController移除目标/文档指针监听，并取消quiz/render和销毁renderer；原库正文逐字节不变。版本升级须重新核对这些内部方法及对应销毁测试。MIT和笔顺数据许可均随构建保留。

原93个MP3仅复制到构建产物，未重新编码或重复提交27MB音频到新源码。开发支持HEAD/206范围与416错误；构建独立包含所有课程音频/笔顺。以后改教材直接维护新content并校验，不从旧补丁链重新抽取覆盖。
